# Lyrics Stats

A small Python project for analysing song lyrics.

The program can search lyrics for specific keywords and phrases, display their occurrences, and provide basic statistics about the words used in a song.

It also groups words by their first letter and uses `Counter` to show word frequencies.

## Features

- Search song lyrics for keywords and phrases
- Display keyword occurrences
- Calculate word frequencies
- Group words by their first letter
- Display lyrics statistics
- Support multiple songs through a simple song/file mapping

## Example

The project currently includes lyrics for:

- Rockabye
- Ciao-Adios

This project is primarily a Python practice project focused on working with files, dictionaries, sets, `Counter`, `defaultdict`, classes, type hints, and separating data processing from presentation.
